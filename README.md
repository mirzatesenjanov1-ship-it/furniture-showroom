# 🛋️ Премиум Коммерциялык Мебель Шоуруму

Бул система коммерциялык эмерек дүкөндөрү үчүн атайын жасалган.

## 🚀 Негизги функциялар

1. **Шоурум Витринасы:** Кардар сайтка киргенде дароо премиум сапаттагы эмеректерди көрөт.
2. **1-Click WhatsApp Буйрутма:** Ар бир эмеректин аты, баасы, өлчөмү жана шилтемеси авто-билдирүү катары түзүлөт.
3. **Корголгон Админ-Панель:** JWT + HttpOnly Cookies, Auth Middlewares аркылуу корголгон.
4. **Ийкемдүү Орнотуулар:** WhatsApp номерин жана дүкөн маалыматын админкадан өзгөртүү мүмкүнчүлүгү.
